# P2.02 Externe Zugänge

**Status:** In Prüfung (Gerätenachweise offen)
**Paket:** P2 · **Planstelle:** [PLAN.md](../PLAN.md), Zeilen 88–104 (Identitäten und Signer); Entscheidung 0002 §4

## Ziel

Wer schon ein Profil in einer anderen App hat, nutzt es in BlueLine, ohne den Schlüssel herauszugeben: Browser-Erweiterung (NIP-07), Signer-App (NIP-46 über QR oder Verbindungslink) oder Android Signer (NIP-55). Vor dem Speichern bestätigt die Person das genannte Konto; das vorhandene Profil wird nur gelesen, nie überschrieben.

## Umfang und Stand

| Teil | Ort |
| --- | --- |
| „Mit einer anderen App“: Erweiterung (nur wo eine erkannt wird oder am Computer, nicht in der installierten iPhone-App), Signer-App (nostrconnect-QR mit `confirm()`, bunker-Link mit Bestätigungsseite), Android Signer (nur Android) | `components/profile/connect-screen.tsx` |
| „Bist du das?“: Name und Bild aus dem öffentlichen Profil, Kennung nur unter „Erweitert“; nichts wird vorher gespeichert; zweite Antwort auf denselben Code: neuer Code | `account-confirm.tsx`, `lib/nostr/signers.ts` (`startNostrConnect`) |
| Danach: eigene Spiele auf diesem Gerät bewusst wählen („Später“ möglich) | `ClaimStep` in `connect-screen.tsx`, `lib/profile/claim.ts` |
| Sitzung je Zugang, Wiederaufnahme nach Neuladen (NIP-46-Sitzung versiegelt), Identitätswechsel der Erweiterung wird abgewiesen, Abmelden sendet NIP-46 `logout` | `lib/profile/session.ts` |
| Android: Anfrage vor dem Verlassen gespeichert, Rückkehr über `/#signer-return` im selben oder neuen Tab, Ablehnung und falsche Signatur erkannt | `lib/profile/android-signer.ts`, `components/profile/signer-return.ts` |
| Bestätigungsseite einer Signer-App während einer Anfrage | `SignerConfirmation` in `components/profile/signer-status.tsx` |
| Öffentlichen Namen ändern nur ausdrücklich („Anzeigename“) oder nach Rückfrage; fremde Felder bleiben; vor der Änderung wird der aktuelle Stand nachgesehen, ohne bekannten Stand wird nichts überschrieben (Review Runde 1) | `edit-sheet.tsx`, `lib/profile/metadata.ts`, `lib/profile/own-events.ts` |
| Ein anderes Profil ist hier angemeldet: „Bist du das?“ führt zum Dialog „Damit wird ‚Name‘ auf diesem Gerät abgemeldet“ (mit Warnung für einen nur hier gespeicherten Zugang); ohne Bestätigung ändert sich nichts, die Signer-Verbindung wird geschlossen (Review Runde 1) | `sign-in-guard.tsx`, `lib/profile/session.ts` (`replace`, `SessionError`) |

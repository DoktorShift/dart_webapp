# P2.02 Externe Zugänge

**Status:** Umgesetzt, Nachweis offen: echte Signer auf Geräten (Amber über NIP-55 und NIP-46, nsec.app, Erweiterungen)
**Paket:** P2 · **Planstelle:** [PLAN.md](../PLAN.md), Zeilen 88–104 (Identitäten und Signer); Entscheidung 0002 §4

## Ziel

Wer schon ein Profil in einer anderen App hat, nutzt es in BlueLine, ohne den Schlüssel herauszugeben: Browser-Erweiterung (NIP-07), Signer-App (NIP-46 über QR oder Verbindungslink) oder Android Signer (NIP-55). Vor dem Speichern bestätigt die Person das genannte Konto; das vorhandene Profil wird nur gelesen, nie überschrieben.
